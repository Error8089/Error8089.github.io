# retr1kze.dev — портфолио

Статичный сайт-портфолио на чистом HTML / CSS / JS. Без сборки, без зависимостей, без билдов.
Проекты и статистика подтягиваются с GitHub API в реальном времени; если API недоступен —
показывается встроенная сохранённая копия.

## Что внутри

- Адаптивная вёрстка: от телефона до широкого монитора
- Тёмная неоновая тема + переключатель акцента (цвет запоминается)
- Живые данные с GitHub: аватар, репозитории, подписчики, язык, звёзды, даты
- Плавные анимации появления, parapallax-подсветка, кастомный курсор на ПК
- Верхняя панель с прогрессом прокрутки и активной секцией
- Мобильное полноэкранное меню
- Поддержка `prefers-reduced-motion` и клавиатурной навигации

## Запуск локально

Просто открой `index.html` в браузере. Либо подними локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открой <http://localhost:8000>.

## Деплой на GitHub Pages

1. Создай публичный репозиторий с именем **`Error8089.github.io`** (имя должно совпадать с логином).
2. Залей сюда все файлы этой папки:
   ```bash
   git init
   git add .
   git commit -m "add portfolio"
   git branch -M main
   git remote add origin https://github.com/Error8089/Error8089.github.io.git
   git push -u origin main
   ```
3. Зайди в **Settings → Pages → Build and deployment** и выбери `Deploy from a branch`,
   ветку `main`, папку `/ (root)`. Сохрани.
4. Через минуту сайт будет доступен по адресу <https://Error8089.github.io>.

> Файл `.nojekyll` уже добавлен — он отключает обработку Jekyll и не даёт «съесть» файлы.

## Что поменять под себя

Всё основное лежит в начале `script.js` в объекте `CONFIG`:

```js
const CONFIG = {
  username: 'Error8089',
  name: 'retr1kze',
  email: 'rootk1tretr0@gmail.com',
  typed: ['веб-интерфейсы', 'Python-код', 'CTF-челленджи', 'что-то новое']
};
```

Тексты секций («Обо мне», «Навыки», «Контакты») редактируются прямо в `index.html`.
Цвета и размеры — в переменных в начале `styles.css`.
