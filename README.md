# retr1kze.dev — портфолио v2 «console edition»

> `guest@retr1kze:~$ open https://error8089.github.io`

Личное портфолио **retr1kze** ([@Error8089](https://github.com/Error8089)) в эстетике
фосфорного CRT-терминала.

## Что внутри

- 🖥️ **Живой терминал** — настоящий шелл-эмулятор: `help`, `neofetch`, `projects`,
  `theme amber`, `matrix`, история команд и автодополнение по Tab
- ⚡ **CRT-boot** — короткая BIOS-заставка при загрузке (пропускается любой клавишей)
- 📦 **Навыки в стиле `pacman -Q`** — потому что Arch, btw
- 🔄 **Живые данные с GitHub** — репозитории, звёзды и форки подтягиваются сами
- 🌿 **Матрица** — команда `matrix` в терминале, `Esc` — выход
- ⌨️ Konami-код — попробуй ↑↑↓↓←→←→BA

## Технологии

Чистые HTML / CSS / JS. Без фреймворков, сборщиков и зависимостей —
как и положено сайту, который грузится мгновенно.

| файл | зачем |
|---|---|
| `index.html` | разметка и контент |
| `styles.css` | CRT-тема, адаптив, анимации |
| `script.js` | терминал, boot, matrix, GitHub API |
